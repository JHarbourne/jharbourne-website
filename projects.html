Static HTML · GitHub Actions · WCAG 2.2 AA · Lighthouse CI · axe-core · Vercel

This site

jharbourne.com is built to the standard it advertises. The footer claim—“WCAG 2.2 AA · keyboard-navigable · fast · cookieless”—is not decoration: it is enforced by a GitHub Actions pipeline that runs on every push. HTML is linted with htmlhint. CSS is checked with stylelint. All eleven public pages are loaded in a real Chromium browser and audited against the full axe-core WCAG 2.2 AA ruleset; the build fails if a violation is found. Lighthouse CI then scores every page for accessibility, performance, best practices, and SEO, with enforced thresholds. No trackers, no external fonts, no cookie banners. Deployed to Vercel on every commit.
